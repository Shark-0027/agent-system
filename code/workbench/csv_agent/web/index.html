① 准备你的 CSV 数据

  • 第一行必须是列名（表头），不要有合并单元格或多级标题
  • 每一列保持同一种类型：数字列纯数值；日期列格式统一；文本列不需要额外引号
  • 编码推荐 UTF-8；文件大小 ≤ 200MB
date,region,product,sales,quantity
2024-01-05,华东,笔记本,7899.00,2
2024-01-06,华南,手机,4299.00,3
2024-01-07,华北,笔记本,7899.00,1

② 填写分析目标（可选）

  • 好的目标包含对象 + 问题：例如「按地区汇总销售额，识别增长最快的区域」
  • 留空则系统会做一次综合探索分析（清洗 → 可视化 → 报告）
  • 也可以直接点下面的 4 个模板 chips（趋势 / 异常 / 建模 / 综合）

③ 典型场景举例

📈 销售数据趋势 + 地区/品类对比 + 异常月份
🏥 医疗数据关键指标分布 + 异常值 + 因素相关
🏭 工业传感器时间序列趋势 + 异常检测 + 分布拟合
🎓 问卷/调研交叉汇总 + 相关分析 + 分组建模
